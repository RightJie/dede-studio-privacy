# dede-studio-privacy
Public privacy policy draft for Dede Studio Android offline trial.

## Published policies

- [嘚嘚画室](https://rightjie.github.io/dede-studio-privacy/) — `index.html`
- [滚得刚刚好 V2.1](https://rightjie.github.io/dede-studio-privacy/rolling-just-right/) — `rolling-just-right/index.html`

The rolling game uses its own page and URL. Its policy describes Android 2.1.0
(21001), local game records and sound settings, offline operation, no declared
Android permissions, and user-initiated email support. The operator and contact
address follow the existing published policy. The original Dede policy is retained.

These are static HTML pages without JavaScript, analytics, external images or
external fonts. GitHub Pages serves the `main` branch. Publishing a policy does
not mean the game or its policy has passed TapTap review.
